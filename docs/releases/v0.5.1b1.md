# Norman v0.5.1b1 — bridge-paced RF rooms (beta)

This opt-in beta only changes the experimental ESPHome RF transport. Gen 1 and
Gen 2 hub behaviour is identical to v0.5.0, which remains the stable release.

## What changes

- With RF bridge firmware **0.12.0-experimental** (protocol 4), a room cover sends
  one command and the bridge sends each section's full burst in turn. Home
  Assistant then checks the bridge until the room finishes.
- A Wi-Fi or API stall during a room no longer stops later sections from being
  sent; the bridge already has the whole room.
- The bridge's automatic repeats cover every section in the room, not only the
  last one. A new command takes over from a running repeat instead of being
  rejected as busy.
- Older bridge firmware keeps the v0.5.0 behaviour: one command per section.

If the bridge reports a failure, or doesn't confirm completion in time, every
section in that room becomes uncertain. Nothing is retried automatically.

## Try the beta

1. Update the RF bridge to firmware 0.12.0-experimental (see the bridge README).
   Install this beta before or with the firmware: v0.5.0 does not accept the
   new bridge status.
2. In HACS, open Norman's three-dot menu, choose **Redownload**, then **Need a
   different version?**, select **v0.5.1b1** and restart Home Assistant.
3. Test a room Open and Close with the shutters in view.

To roll back, select **v0.5.0** the same way and restart. Older bridge firmware
works with both versions.
