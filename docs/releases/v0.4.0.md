# 0.4.0 — Gen 1 and Gen 2 (ShadeAuto)

Prepared on main; no tagged release has been published yet.

- Adds a generation choice during setup and a separately attributed ShadeAuto backend based on keito's local API.
- Preserves existing Gen 1 entries, entity IDs, movement profiles and battery sensors.
- Adds ShadeAuto position/tilt and nudge controls, notification updates, stable hub-scoped identities, bounded response parsing and connection cleanup.
- Uses current Home Assistant action selectors and preserves the other rail when controlling a single rail.
- Renames the displayed integration and HACS entry to Norman. The internal `norman_gen1` domain remains for compatibility.
- Documents installation for both generations with separate operating guides.

Validation includes the minimum and current HA test lanes, existing Gen 1 hardware
readback and a real HA runtime using a ShadeAuto HTTP fixture. Physical Gen 2
hardware qualification remains outstanding. See the
[verification record](../aegis/work/2026-09-10-gen2-shadeauto/90-evidence.md).
