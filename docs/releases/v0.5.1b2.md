# Norman v0.5.1b2 — reliable RF room sections (beta)

This opt-in beta only changes the experimental ESPHome RF transport. Gen 1 and
Gen 2 hub behaviour is identical to v0.5.0, which remains the stable release.
It replaces v0.5.1b1.

## What changes

- RF room covers send each section as its own command. In camera-checked trials
  this moved 32 of 32 lounge panels, while sending a room as one bridge-run
  sequence (v0.5.1b1) repeatedly missed one panel.
- With RF bridge firmware 0.12.0-experimental (protocol 4), a lost reply from
  the bridge no longer stops the rest of the room. Home Assistant checks the
  bridge's record of that command: a completed burst counts as sent, a command
  the bridge never accepted is reported as not sent, and anything else is
  uncertain. The remaining sections are still sent.
- If any section can't be confirmed, the action reports which ones, after
  every other section has been sent. Nothing is retried automatically.
- Older bridge firmware keeps the v0.5.0 behaviour.

## Try the beta

In HACS, open Norman's three-dot menu, choose **Redownload**, then **Need a
different version?**, select **v0.5.1b2** and restart Home Assistant. Then test
a room Open and Close with the shutters in view.

To roll back, select **v0.5.0** the same way and restart. Bridges on firmware
0.12.0 need v0.5.1b1 or later, because v0.5.0 does not accept their status.
