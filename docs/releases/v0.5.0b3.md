# Norman v0.5.0b3 — Gen 2 room controls (beta)

This is an **opt-in beta**, not the stable update. The maintainer only owns a Gen 1
hub; physical Gen 2 room operation needs your feedback. Automated tests use
simulated ShadeAuto responses and do not prove every hub or blind model works.
Stable v0.4.1 remains available and unchanged.

## What changes

- Each discovered ShadeAuto room gains a separate **Shades** cover, alongside its
  existing individual covers.
- Room open, close, position, tilt and nudge controls use the existing individual
  shade commands sequentially. They are not a native simultaneous broadcast.
- Each shade preserves its own other rail. Unknown required positions prevent
  the command; a partial failure stops further commands and reports uncertainty.
  There are no automatic retry movements.

This beta also includes the existing v0.5 ESPHome RF work and Home Assistant
schema-compatibility fixes from main. Existing Gen 1 and individual Gen 2 controls
remain available. No hardware firmware update is required by this change.

## Try one room

1. Back up Home Assistant and note your currently installed Norman version.
2. In HACS, open Norman's three-dot menu, select **Redownload**, then **Need a
   different version?**, and select **v0.5.0b3**. Older HACS versions may also need
   **Show beta versions** enabled. Restart Home Assistant after installation.
   If the release is missing, try **Update information** first. If your HACS version
   still does not offer this release, use the manual
   installation method in the README with this release's source archive.
3. Under **Settings → Devices & services → Norman**, find one Gen 2 room's new
   **Shades** cover. Keep the physical shades in view and their travel paths clear.
4. Try **Open**, then **Close**, then a mid-position. Confirm that every shade in
   that room responds and shades in other rooms stay still. Sequential movement
   is expected. Check that individual controls still work.
5. Only if your individual covers already support the second rail, try a room
   tilt adjustment and check that the other rail stays where it was.

If any command fails or moves an unexpected shade/rail, stop testing and check
the actual positions before another command. Report what happened on issue #26,
including the Norman and Home Assistant versions. Do not share passwords,
tokens, hub addresses or account information. No API capture is needed initially.

## Return to your previous version

Use HACS's version selection to reinstall the version you recorded, then restart
Home Assistant. Do not delete and recreate the integration. If configuration
restoration is needed, restore the pre-test Home Assistant backup. The beta does
not change existing individual-cover identities; room entities are a beta addition.

HACS documents [specific-version downloads](https://hacs.xyz/docs/use/repositories/dashboard/#downloading-a-specific-version-of-a-repository)
and its optional [pre-release update switch](https://www.hacs.dev/docs/use/entities/switch/).
You do not need to enable ongoing beta updates just to select this test version.
