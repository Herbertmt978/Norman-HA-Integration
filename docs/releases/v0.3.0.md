## Highlights

- Open and Closed are now user-configurable raw hub positions. New installations
  default to Open `37` and Closed `100`; Closed can be reversed to endpoint `0`.
- Defaults can be overridden per room or per panel. Panels inherit their room,
  and rooms inherit the global defaults, until explicitly pinned.
- Compatible room Open/Close actions use the hub's live-verified room broadcast,
  so all panels start together. Mixed or non-native overrides use exact panel
  targets in one serialized hub transaction.
- Each physical motor now exposes a translated diagnostic battery percentage.
  Battery values reuse the existing 60-second hub snapshot and add no poll,
  login, cookie, or network request.
- Native Home Assistant cover controls and the arbitrary-position slider remain;
  no duplicate button entities were added.

## Upgrade notes

- Existing v0.2 movement choices are migrated to equivalent numeric profiles
  after the first successful hub discovery, preserving their effective Open and
  Closed directions.
- Existing cover unique IDs, entity IDs, user renames, and automation targets are
  preserved. Legacy hub and room registry identities are migrated without
  duplicating the new battery entities.
- Restart Home Assistant after installing the update through HACS.
