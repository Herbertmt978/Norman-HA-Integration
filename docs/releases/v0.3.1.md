## Highlights

- Motor-battery diagnostics now use the same panel names shown under Controls.
  This replaces inconsistent hub-internal labels such as generated IDs,
  unexpected casing, or installation names that do not match the commandable
  panel.
- When one commandable panel contains more than one physical motor, its battery
  sensors use translated `motor 1`, `motor 2` suffixes in the hub's panel-slot
  order, with the physical window ID as a deterministic fallback.
- Physical window IDs remain the battery entity identity, so existing entity
  IDs, user-assigned names, and automations are preserved.
- A change to a known motor's correlated panel label or motor number triggers
  one supported config-entry reload so every sensor is renamed consistently.

## Upgrade notes

- Restart Home Assistant after installing the update through HACS so existing
  battery entities are reloaded with their correlated panel names.
- Shutter commands, position profiles, polling, and hub authentication are
  unchanged in this patch release.
