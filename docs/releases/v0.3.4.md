## Fix

Use the registered Norman hub's device ID for room-device parent links on newer
Home Assistant versions. This replaces the deprecated `DeviceInfo.via_device`
field where its replacement is available, including when a battery sensor moves
between rooms.

The integration still supports Home Assistant 2024.11. Older supported versions
continue to receive the legacy parent-link field.

## Upgrade notes

- Update through HACS and restart Home Assistant.
- No configuration or entity migration is required.
- Existing entity IDs, names, room command modes, position profiles, and
  automations are unchanged. No additional hub polling or movement commands are
  introduced.
