# 0.4.1 — ShadeAuto reliability fixes

Update through HACS and restart Home Assistant. No reconfiguration is required.

- Consecutive position, tilt and nudge commands preserve the last accepted rail targets while the hub catches up. Commands and status reads are serialized; pending targets clear when acknowledged or after 30 seconds.
- Notification connection timeouts now use the normal retry delay and status recovery, instead of being mistaken for scheduled stream rotation.
- Invalid rail values are rejected before they reach entity state or control requests.

Gen 1 behavior and identifiers are unchanged. Validation covers the three reported
failures, overlapping commands, rejected commands, target acknowledgement/expiry,
and Gen 1 regression tests on the supported Home Assistant test environments.
