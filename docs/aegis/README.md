# Aegis engineering records

This directory records the verified baseline, compatibility decisions, and
implementation plans used for substantial changes to the Norman Gen 1
integration.

- `baseline/` contains dated, evidence-backed starting points.
- `plans/` contains executable plans whose tasks are implemented test-first.
- `BASELINE-GOVERNANCE.md` defines when a baseline may be replaced.
- `INDEX.md` links the active records.

These records support this HACS repository. A future Home Assistant Core pull
request must still be prepared against the then-current Core development tree.
