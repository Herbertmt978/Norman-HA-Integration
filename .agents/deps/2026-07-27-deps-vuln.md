# Dependency vulnerability review — 2026-07-27

## aiohttp

`requirements_test.txt` now pins `aiohttp==3.14.1`. This is the first release
patched for all eleven open aiohttp advisories affecting the previous 3.13.5
pin (Dependabot alerts 2–12).

## pycares compatibility exception

Dependabot alert 1 remains open for `pycares==4.4.0` in
`requirements_ha_minimum.txt`. That file is only used by the CI compatibility
harness for the declared Home Assistant 2024.11 minimum; it is not an
integration runtime dependency manifest.

Updating this pin to 4.9.0 was tested by Dependabot PR 7. All 89 integration
tests passed, but the Home Assistant 2024.11 test harness then failed teardown
because pycares left `_run_safe_shutdown_loop` running. Keeping 4.4.0 therefore
preserves the repository's documented minimum-version test gate.

The alert has not been dismissed. Revisit the pin when either:

- a patched pycares release no longer leaves the shutdown helper thread in the
  Home Assistant 2024.11 harness; or
- the project's supported Home Assistant minimum is deliberately raised in a
  separate change.
